# openEDR - An openEHR-Based Data Modeling
This project was developed as part of the "Current Research and Trends in Health Informatics" course in the Health Informatics Master's Program at Karolinska Institutet. It focuses on designing a unified, standards-based framework that integrates Electronic Health Records (EHR) and Electronic Dental Records (EDR) using the openEHR specification, referred to as openEDR, to enhance data standardization and interoperability between EHR and EDR systems, and to fulfill the specific medical information needs of Swedish dental care.


## Methodology
### Information Needs Assessment
Conducted through:
1. Analysis of the PAERH (Patient Accessible Electronic Health Record) system
- Literature review
- Surveys

2. Conceptual Modeling
- Modeled identified medical information needs using Unified Modeling Language (UML) Class Diagrams
- Translated the conceptual model into openEHR templates and archetypes

## Results
- Developed 12 openEHR templates
- Reused and modified 88 existing archetypes to align with the specific needs of Swedish dental care
